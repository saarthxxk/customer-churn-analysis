# Customer Churn Analysis Dashboard (Tableau)

## Project Overview
This project analyzes customer churn data to identify key factors influencing customer retention and attrition.

## Objectives
- Identify which customers churn
- Understand when churn happens
- Discover why churn happens

## Key Insights
- Churn is highest among new customers (0–10 months tenure)
- Low product usage strongly correlates with churn
- Lower satisfaction scores lead to higher churn rates
- Payment failures significantly increase churn probability
- SME customers show slightly higher churn rates
- Gender has minimal impact on churn

## Tools Used
- Tableau
- Excel / CSV dataset
